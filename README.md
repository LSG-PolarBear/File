# 🔥 Fire - 剪贴板循环发送器

**Fire** 是一个基于 Python 的 Windows 桌面工具，可将剪贴板内容快速、循环地粘贴并发送至聊天窗口（如微信、QQ 等）。  
支持**自定义发送间隔**、**极速模式（最高 50 条/秒）**，界面简洁置顶，操作方便。

> ⚠️ **严正警告**  
> 本工具仅用于学习 **Python 自动化、键盘模拟、剪贴板操作** 等编程技术，**严禁用于骚扰、刷屏、广告等违规行为**。  
> 使用极速模式极易触发平台风控，导致**账号禁言、功能限制甚至永久封禁**，后果自负。

---

## ✨ 功能

- ✅ 窗口**始终置顶**，半屏大小，好操作
- ✅ 实时显示剪贴板内容预览
- ✅ 拖动**滑块**自定义发送间隔（0 ~ 3 秒）
- ✅ **极速模式**：勾选后无视滑块，通过下拉菜单直接选择速度档位  
  - 10 条/秒、20 条/秒、30 条/秒、40 条/秒、50 条/秒（物理极限）
- ✅ **固定内容模式**：开启后不再反复读取剪贴板，进一步压榨性能
- ✅ 醒目的**开始**/**紧急停止**按钮，随时终止循环
- ✅ 使用 `threading.Event` 精确控制间隔，停止无延迟
